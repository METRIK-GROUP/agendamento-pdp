Como funciona

Três passos. Cinco minutos.

Você escolhe o horário na agenda do Rodrigo, logo abaixo. O Google cuida do resto: evento, link do Meet e confirmação.

  3. 3

    No dia, entre pelo link

Importante

Regras da sessão

Combinado antes para ninguém perder o bônus.

  • Há vagas para todos, então novos horários não serão abertos. Se você esquecer de agendar e não houver mais horários, o bônus é perdido.
  • Remarcação só é possível enquanto ainda houver outros horários disponíveis.
  • Não comparecer conta como bônus utilizado. Sem reagendamento.
  • Organize-se para aproveitar integralmente os 25 minutos.
  • Programe um alarme para não perder o horário.

Cancelamento e remarcação

Para cancelar: use o link no e-mail de confirmação, ou exclua o evento no seu Google Agenda, com pelo menos 24h de antecedência.

Para remarcar: use o link de remarcação no e-mail de confirmação, ou agende um novo horário na agenda acima e cancele o anterior. Só é possível remarcar se ainda houver horários disponíveis.
